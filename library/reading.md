# Reading a source

Choose a source with `list`, then inspect its bodies with `show`. A work, its translation or edition,
and a stored body have distinct identities. Read mediation, coverage and rights metadata before use.
Configure an external archive folder and run `verify` before reading. The reader checks the selected
body again on every request. Query results include the edition, translator, exact digest and a replayable
locator. Preserve that locator with quotations. A source's relation to a question determines whether it
is primary evidence; collection membership alone does not establish that role.
